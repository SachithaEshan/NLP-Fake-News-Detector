# NLP-Fake-News-Detector

A Natural Language Processing (NLP) project to classify news articles as **fake** or **factual** using machine learning.

---

##  Project Overview

With misinformation spreading rapidly online, this project aims to build an automated detector for fake news. The pipeline includes:

1. **Data Cleaning & Preprocessing**: Tokenization, stopword removal, lemmatization, and TF-IDF vectorization.  
2. **Exploratory Analysis**: Word clouds, frequency plots, and comparison of linguistic characteristics.  
3. **Model Building**: Training classifiers such as Logistic Regression, Naive Bayes, and optionally LSTM.  
4. **Evaluation & Visualization**: Computing accuracy, precision, recall, F1-score, confusion matrices; visual comparisons through plots.  
5. **Stakeholder Insights**: Visual outputs and metrics supporting decisions on model deployment and improvements.
